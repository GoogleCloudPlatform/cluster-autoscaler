# Contributing

**Do not modify the files in this directory manually.**

This directory is automatically imported from
[cluster-autoscaler/cloudprovider/gce](https://github.com/kubernetes/autoscaler/tree/master/cluster-autoscaler/cloudprovider/gce)
in the upstream [kubernetes/autoscaler](https://github.com/kubernetes/autoscaler) repository.
Each import replaces the contents of this directory with the upstream code, so
manual changes will be lost.

To change this code, contribute the change to kubernetes/autoscaler. Once it is
merged upstream, the next automatic import picks it up.
